# Навык: Antigravity CLI (Google)

Antigravity — AI-IDE от Google. Необязательный CLI `agy` устанавливается и авторизуется владельцем отдельно. Сначала проверь наличие бинаря и входа.

## Где
- Бинарь: `__NOOK_USER_HOME__/.local/bin/agy` (в PATH).
- Авторизация Google OAuth: через `agy` (TUI), нужен TTY (tmux/script).

## Использование
- Интерактив: `agy` (нужен TTY; в фоне — через tmux).
- Разовый запрос (печать): `agy --print "промпт"` / `agy -p "..."` (не требует TUI).
- Продолжить диалог: `agy --continue`.

## Агенты/модели
- `agy agent` — список агентов; `agy models` — модели.

## Безопасность
- Автономное выполнение кода рискованно: по умолчанию спрашивает разрешения;
  не использовать `--dangerously-skip-permissions` без необходимости.
- Данные уходят в Google (ToS). Для конфиденциального — не использовать.
