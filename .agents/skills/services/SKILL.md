# Навыки и сервисы Nook

Всё это — только для тебя (не трогай общий `~/.codex/config.toml` хозяина).

## Новый навык («научись …»)

Навык = папка `~/nook/.agents/skills/<имя>/SKILL.md` (имя латиницей, через дефис):

```
---
name: <имя>
description: <что умеет и КОГДА применять — по этой строке ты решаешь, открывать ли навык>
---
# Инструкция: шаги, команды, пути, подводные камни. Коротко и по делу.
```

Если нужны скрипты — клади рядом (`scripts/`) и проверь, что работают. Подробности — системный навык `skill-creator`.
Навык подхватится со следующей задачи. Скажи хозяину одной строкой, чему научился.

## Новый сервис (MCP-сервер)

Конфиг: `~/nook/.codex/config.toml`. Формат:

```toml
[mcp_servers.github]
command = "npx"
args = ["-y", "@modelcontextprotocol/server-github"]
env_vars = ["GITHUB_PERSONAL_ACCESS_TOKEN"]   # берётся из окружения Nook
# enabled = false                              # временно выключить
```

Удалённые (HTTP): `url = "https://…/mcp"` (+ `bearer_token_env_var = "X_TOKEN"`).

Порядок:
1. Найди официальный MCP-сервер сервиса (сайт сервиса / github.com/modelcontextprotocol/servers / npm / PyPI). Не ставь
   сомнительные пакеты от неизвестных авторов — скажи хозяину, что нашёл, и спроси.
2. Есть `node`/`npx`, `uvx`, `python3`, `docker`.
3. Если нужен ключ/токен: попроси хозяина прислать его **файлом или сообщением**, положи в `~/nook/secrets.env`
   (`KEY=value`, chmod 600) — бот загружает его в окружение при каждом запуске. Никогда не повторяй секрет в ответе.
4. Добавь секцию в конфиг, проверь: `cd ~/nook && codex mcp list` (статус) и реальным вызовом инструмента.
5. Запиши в notes.md: что подключено и зачем. Хозяину — одной строкой.

Инструменты нового сервиса станут доступны со следующей задачи.

## Без MCP

Многое проще сделать CLI-утилитой или скриптом в `~/nook/bin` (в PATH) + навыком с описанием, как её звать.
Предпочитай это, если сервис даёт простой HTTP API.
