# Боты хозяина

## Где они

- Инвентарь — `memory/registry.json` (поле `path`, `start`, `autostart`, `expected`). Начинай с него.
- `~/bots/*` — боты текущего пользователя. Часть запускает `~/bots/st.py` (список `programs` в нём; лог `~/bots/autostart.log`).
- pm2: `pm2 ls`, `pm2 logs NAME --lines 80 --nostream`.

## «Бот не отвечает» — порядок

1. Процесс жив? (`pm2 ls` / `systemctl --user status` / `ps aux | grep <файл>` по `procs` из registry).
2. Свежие ошибки в логах (pm2 / journalctl / nohup.out / свой лог проекта).
3. Токен жив и нет конфликта: `tgapi --token-file <файл>:<ПЕРЕМЕННАЯ> getMe` и `… getWebhookInfo`.
   - `401 Unauthorized` — токен отозван: нужен новый от @BotFather (скажи хозяину, куда его положить).
   - `409 Conflict` — бот запущен дважды (два polling) или висит вебхук: найди второй процесс.
   - `pending_update_count` большой + `last_error_message` — вебхук сломан.
4. Перезапусти тем способом, которым он запускается (registry `start`), проверь, что поднялся и не падает через минуту.
5. Запиши в journal.md, если что-то менял; в notes.md — если узнал что-то полезное про бота.

## Заметки

- Не запускай второй экземпляр поверх живого — получишь 409.
- Код ботов правь только с бэкапом файла рядом (`file.bak-YYYYMMDD`) и только если причина очевидна.
