# GitHub

Прочитай `docs/GITHUB.md`. Проверь `bin/github-api /user`, прежде чем писать от имени аккаунта. Если GitHub ещё не настроен, предложи владельцу подключение через `python3 install.py --github-only`: свой аккаунт, отдельный аккаунт агента или позже. Аккаунт регистрирует человек, пароль не запрашивай. Токен вводится скрыто или читается из приватного файла, в чате его не повторяй.

Используй `bin/github-git` вместо обычного Git для clone/commit/push к GitHub по HTTPS: он применяет отдельную личность и ключ этой копии. Не меняй глобальный Git или чужие ключи. Токены только в `secrets.env`, не в URL, аргументах или памяти. `bin/github-api /repos/OWNER/REPO/pulls --method POST --json` принимает JSON тела из stdin. Пиши во внешние проекты только по поручению хозяина; готовь изменения и проверяй их перед PR. При 403 проверь права токена, collaborator-доступ и ограничения fine-grained PAT; не объявляй PR созданным без ссылки от GitHub.
